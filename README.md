# Unità d'Italia — sito didattico (GitHub Pages)

## Pubblicazione
1. Crea un repository su GitHub
2. Carica i file di questa cartella nella **root** del repository
3. GitHub → Settings → Pages → Deploy from branch → `main` / `(root)`
4. Apri l’URL che GitHub ti mostra.

## Struttura
- `index.html`
- `assets/css/app.css`
- `assets/js/app.js`
- `assets/img/` (immagini)
- `assets/Unita_d_Italia.pdf` (PDF allegato)

## Funzioni
- Tema chiaro/scuro
- A− / A+ (dimensione testo)
- Stampa
- Ricerca nell’indice
- Click-to-zoom immagini (ESC per chiudere)
